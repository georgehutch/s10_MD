# s10_MD
Molecular dynamics parameters and analysis files for Amber simulation of a RNA-bouns stapled s10 peptide. 

# Contents
1) staple_params = Amber parameters for staple residue fragments
2) MD_setup = LEaP input file, pdb input file, and AMBER output files used in preparation of simulations
3) MD_submission = AMBER MD settings and slurm submission script for 50 ns trajectory
4) cpptraj_analysis = Analysis scripts for processing trajectory and calculating RMSD, RMSF, and peptide binding clusters
5) cluster_results = Representative structure of 5 clusters, and statistics of the clustering analysis
